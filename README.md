# WDD 430 Portfolio

A personal portfolio built for WDD 430 using Next.js, TypeScript, and Tailwind CSS.

## Live Site

https://wdd430-portfolio-git-main-wdd433.vercel.app/

## About the Project

This portfolio showcases some of my web development projects and the technologies I have worked with.

The application was built with the Next.js App Router and uses reusable Server Components for the layout and project content.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Pages and Routes

- `/` — Home page and project showcase
- `/about` — About me and skills
- `/api/hello` — Simple Next.js API route

## Components

The portfolio includes reusable components such as:

- `Header`
- `Footer`
- `ProjectCard`
- `ProjectList`
- `SkillCard`

`SkillCard.tsx` is my custom component. It accepts a skill name and description as props and displays them using Tailwind CSS styling.
